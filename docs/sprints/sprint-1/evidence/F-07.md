# F-07 verification

Tested locally on 2026-11-06 against Sprint 1 staging base `56e816c` with the F-07 changes applied. The PostgreSQL 18.6 instance used a separate `cpms_f07_test` database and synthetic seed data.

## Test-first evidence

Before registering the read handlers and implementing the status rules, `npm test -w server -- tests/scoped-views-db.test.ts tests/milestone-status.test.ts` reported **2 failed files, 7 failed tests**. Representative assertion output:

```text
TEST-35 scopes student reads and returns only the public fields
Error: expected 200 "OK", got 404 "Not Found"

TEST-37 gives feedback and submission precedence over the deadline
AssertionError: expected 'NOT_SUBMITTED' to be 'REVIEWED'

TEST-37 only marks unsubmitted work overdue after the deadline
AssertionError: expected 'NOT_SUBMITTED' to be 'OVERDUE'
```

After implementation, `npm test` reported **14 passed files, 94 passed tests, 1 skipped**, including all seven F-07 tests. The existing local-secret check skipped because there was no repository `.env`. `npm run build` built the server and client. Vite emitted dependency warnings about React Router's `"use client"` directives.

## Seeded response timing

Ten sequential iterations on local Windows with Node 24 and PostgreSQL 18.6. Each iteration signed in as seeded student A1 and sent its session cookie with the team list, team detail and milestone detail requests. A Node `fetch` timer on loopback measured elapsed time through reading each response body.

| Request | Median | Maximum |
|---|---:|---:|
| Login | 62.7 ms | 73.2 ms |
| Team list | 6.1 ms | 10.2 ms |
| Team detail | 5.2 ms | 9.8 ms |
| Milestone detail | 4.3 ms | 6.4 ms |

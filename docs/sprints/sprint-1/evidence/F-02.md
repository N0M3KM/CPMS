## Dependency audit (AC-16)

The 3 high findings came from `deepmerge-ts` below 8.0.0 inside the Prisma CLI. The root `package.json` now overrides it to `^8.0.2`. Evidence: `F-02-audit.txt`. `npm audit` reports 0 vulnerabilities; `prisma validate`, `npm run db:deploy`, `npm test` (12 files, 88 tests), `tsc` and `npm run build` all succeed with it. Prisma 6.19.3 declares `deepmerge-ts` 7.1.5, so `npm ls` flags it as invalid by design; this is a known cost of the override. Revisit when Prisma publishes a release that depends on 8.x.

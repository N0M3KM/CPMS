# F-03 verification

Verified locally on 2026-11-06 from Sprint 1 staging base `000c09f` with the F-03 changes applied. The tests used synthetic accounts and a separate PostgreSQL 18.6 test database.

## Test-first evidence

Before the milestone POST route was registered, `npm test -w server -- tests/create-milestone-db.test.ts` reported **1 failed file and 4 failed tests**. Representative output:

```text
TEST-17 persists boundary-length milestones and lists them for the team
Error: expected 201 "Created", got 404 "Not Found"

TEST-19 rejects a past deadline and one equal to the current instant
Error: expected 400 "Bad Request", got 404 "Not Found"

TEST-20 and AC-11 deny students, anonymous callers and foreign supervisors
Error: expected 403 "Forbidden", got 404 "Not Found"
```

After implementation, `npm test` reported **15 passed files, 98 passed tests, 1 skipped**. The existing local-secret check skipped because the repository had no `.env`. `npm run build` built the server and client. Vite emitted the existing React Router dependency warnings.

## Acceptance checks

| Test | Observed result |
|---|---|
| TEST-17 | The assigned supervisor created milestones with 5- and 100-character titles, optional and 1000-character descriptions, and a future deadline. PostgreSQL stored the session user as creator. A student on the same team could read both milestones as `NOT_SUBMITTED`. |
| TEST-18 | Out-of-range or missing fields, invalid ISO dates, a forged creator ID and malformed team ID returned 400. The milestone count did not change. |
| TEST-19 | Deadlines before and exactly at the fixed clock instant returned 400 without inserting rows. |
| TEST-20 and AC-11 | The student received 403 and the anonymous caller received 401. Foreign and missing teams produced identical 404 responses. No row was inserted. |
| TEST-42, F-03 portion | Playwright exercised inline validation, disabled pending controls and recovery from an injected 503. The supervisor then created a milestone through the real API, saw it in the refreshed list, and reloaded it. A student could read it with no creation form, and a direct student POST returned 403. The submission step depends on F-04. |
| TEST-40, creation | Ten sequential authenticated POSTs through Vite's loopback proxy returned 201. Browser timing from request to response body was **10.7 ms median, 14.7 ms maximum**. |

The first browser run timed out because the final database test had left the isolated database without teams. The successful rerun explicitly seeded the database before starting the browser.
